# Slop Hong Kong

A Hong Kong City simulation built with [three.js](https://threejs.org/), WebGPURenderer, and TSL. Explore Hong Kong on foot, by car, by bicycle, or by helicopter.

Explore other cities and community remixes in [Slop Cities](https://github.com/zz85/slop-cities).
